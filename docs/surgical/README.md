# Surgical robotics project

The active project is a **surgical thread-insertion robot** using
MuJoCo and PufferLib 5.0. The user selected this direction on October 5, 2026.

Read the [active project plan](../neural_insertion/README.md) and
[brief](../neural_insertion/BRIEF.md).

The earlier [dVRK proposal](DVRK_PROPOSAL.md) and
[original brief](DVRK_BRIEF.md) are preserved as research history. Their robot,
task choices and effort estimates do not describe the active insertion project.

Implementation proceeds in the primary checkout on `main`, as requested. Fly
experiments remain on `feature/fly-brain` in their own local workspace.
