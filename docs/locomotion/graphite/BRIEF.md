# Native dark presentation

Pause the generative-video experiment and improve MuJoCo's own visual quality.
Check whether the robot's visible name can be removed. Give the scene and video
overlays a distinctive darker look, using blacks and grays so simulation colors
stand out.

Scope: opt-in presentation for the adaptive walking, standing and moving-support
dog. Preserve vendor assets, physical model parameters, controllers, accepted
checkpoints, original movies and release tags. Make a static preview first, then
show the same accepted moving trajectory with the new overlays and native renders.

Palette: near-black canvas, graphite floor, neutral metal robot, muted white/gray
type. Teal identifies task supports and contact state; orange identifies physical
limb removals. Branding is integral to the mesh, so thin curved observer-only body
panels cover the raised/recessed letters. These panels add no collision or mass.
